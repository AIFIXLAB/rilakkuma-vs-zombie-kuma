## แก้บั๊กที่พบระหว่างทดสอบ

- ซอมบี้ฮีลซ้อนกันจนไม่ตาย → จำกัดการฮีล 1 ครั้ง/วิ, รัศมี 0 ฮีลตัวเอง
- ด่านค้าง (ตัวป้องกันถูกฮีล vs ซอมบี้ถูกบล็อก) → ซอมบี้ "คลั่ง" เมื่อเกมยืดเยื้อ
- VS: CPU ฝั่งซอมบี้ไม่ปล่อยตัว (คูลดาวน์ undefined), ฐานซอมบี้ไม่ถูกตี → แก้แล้ว
- บอทสแปมข้อความแจ้งเตือน, วางกับดักซ้ำช่อง → แก้แล้ว
- บอส 5 ตัว (Tank, Tentacle, Toxic Slime, Spike Armor, Final King) หายไปในเวอร์ชัน atlas → ตัวรวมภาพใช้รายการภาพที่เกมใช้จริงแล้ว

## ข้อจำกัดของการทดสอบ

- ไม่ได้ทดสอบบน iPad จริง (ทดสอบ Chrome + touch ขนาดจอ iPad) — ควรลองบน Safari iPad: เสียง, Add to Home Screen, ความลื่น
- ความสมดุลวัดด้วยบอท คนเล่นจริงอาจรู้สึกง่าย/ยากต่างไป — ปรับตัวเลขได้ใน `data/stages.js`
- ออนไลน์ไม่ได้ทดสอบเพราะไม่มีเซิร์ฟเวอร์
- ประสิทธิภาพวัดบน CPU เดสก์ท็อป (ซอมบี้ 110 ตัว ~ ดูตาราง Perf) — iPad รุ่นเก่าอาจช้ากว่า มีตัวเลือกกราฟิก ต่ำ/กลาง/สูง ในตั้งค่า
