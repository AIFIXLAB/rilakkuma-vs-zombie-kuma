# RILAKKUMA vs ZOMBIE KUMA — Full Version 1.0

เกม Tower Defense แนวตั้งฉากบน iPad (แนวนอน) — HTML5 Canvas + JavaScript ล้วน ไม่มี build, ไม่มี npm
ใช้ภาพจากชุด `kumazombie.zip` ของผู้ใช้เท่านั้น (ไม่ได้วาดภาพแทน) · เพลงประกอบแต่งสดแบบ generative

## 🚀 อัปขึ้น GitHub + Vercel

ทั้งโปรเจกต์มี **ไม่ถึง 100 ไฟล์** (ภาพตัวละคร/ซอมบี้/UI รวมอยู่ใน atlas 4 แผ่นใน `Assets/atlas/`) → อัปผ่านหน้าเว็บ github.com ได้ในครั้งเดียว

1. github.com → **New repository** → ชื่อ `rilakkuma-vs-zombie-kuma` → *Create*
2. ในหน้า repo กด **uploading an existing file** (หรือ *Add file → Upload files*)
3. แตกไฟล์ zip ในเครื่อง → เปิดโฟลเดอร์ `rilakkuma-vs-zombie-kuma` → **เลือกทุกอย่างข้างใน** แล้วลากใส่หน้าเว็บ (ลากโฟลเดอร์ได้ โครงสร้างโฟลเดอร์คงเดิม) → *Commit changes*
4. vercel.com → **Add New → Project** → Import repo นี้ → Framework Preset: **Other** → ไม่ต้องตั้ง Build Command / Output → **Deploy**
5. เปิดลิงก์ `https://<ชื่อ>.vercel.app` บน iPad ใน Safari → ปุ่ม Share → **Add to Home Screen** = เล่นเต็มจอเหมือนแอป

> macOS ซ่อนไฟล์ `.gitignore` / `.vercelignore` (กด `Cmd + Shift + .` ใน Finder) — ถ้าไม่ได้อัปสองไฟล์นี้ เกมก็ยังทำงานปกติ
> อัปเดตเวอร์ชันใหม่: อัปไฟล์ทับใน GitHub → Vercel deploy ใหม่ให้เอง · เซฟของผู้เล่นอยู่ในเครื่อง (localStorage) ไม่หาย

**เปิดบน PC:** `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000` (ต้องเปิดผ่านเซิร์ฟเวอร์ เพราะ atlas ต้องโหลดภาพจากโดเมนเดียวกัน)

### ในสนาม
- **หมุนตัวละคร ซ้าย/ขวา** — แตะตัวละคร → ปุ่ม "หมุน" → หันหลังยิงซอมบี้ที่หลุดผ่านไปแล้ว (มีลูกศรบอกทิศ)
- **ขายตัวละคร** — แตะตัวละคร → "ขาย" ได้โดนัทคืน 50% ของที่ใช้ (ตัวที่บาดเจ็บได้คืนลดลงตาม HP) → ช่องว่างวางตัวใหม่ได้ทันที
- **กับดัก 15 แบบ** ซื้อในร้านกับดัก → เข้ากระเป๋า → แท็บ "กับดัก" ในแถบการ์ด → วางบนช่อง (ใช้โดนัทเล็กน้อย) · แบบเหยียบ/ทำงานต่อเนื่อง/ใช้ครั้งเดียว
- **สกิลทีม 3 แบบ** (คุมะถล่ม / แช่แข็ง / ฮีล) ชาร์จจากการกำจัดซอมบี้
- เครื่องโดนัท Lv1–5, เก็บโดนัทด้วยมือ, บูสเตอร์ก่อนเข้าด่าน, ×1/×2, หยุดเกม
- ศัตรู 78 แบบ: บิน, กระโดดข้าม, มุดดิน, ฮีลเพื่อน, เรียกพวก, ระเบิด, ออร่าช้า, แยกร่าง, วาร์ป, ดูดเลือด, ยิงไกล, โล่, เกราะ · บอสมีเฟส + สกิล + แถบ HP

### ทีม & ตัวละคร (37 ตัว)
- **จัดทีม 5 ชุด** (ตั้งชื่อได้) ทีมละ 8 ตัว · แตะสลับตำแหน่ง · กรองตามบทบาท · ทีมที่เลือกใช้ทุกโหมด
- ผลิต 2 · ป้องกัน 8 · โจมตี 21 · สนับสนุน 3 · พิเศษ 3 · ระดับ Common → Legend
- อัปเกรด 7 แท็บ: **Level** (เพดานตามดาว) · **Star ★1–6** (ใช้เศษ) · **Skill Lv1–5** · **สายอัปเกรด 3 ทาง** · **Awakening** · **อุปกรณ์ 8 ชิ้น** · **ชุดแต่งตัว** (เปลี่ยนสีภาพจริงในสนาม) — ทุกขั้นยืนยันก่อนหัก
- คลังภาพ: ตัวละคร + สมุดซอมบี้ (ตัวที่ยังไม่เจอเป็นเงา)

### ร้านค้า & เศรษฐกิจ
- **ร้านค้า 6 แท็บ:** ร้านโดนัท/บูสเตอร์ · ร้านตัวละคร · ร้านวัตถุดิบ+อุปกรณ์ · **ร้านกับดัก** · ร้านชุดแต่งตัว · ร้านพิเศษรายวัน (ลด 30–50%) — มีจำกัดจำนวน, ปลดล็อกตามเมือง
- **กาชา 5 ตู้:** ตัวละคร, Rate-Up, ซอมบี้ (การ์ด VS), ชุด, วัตถุดิบ · สุ่ม 1/10 (10 ครั้งการันตี Rare+) · Pity 60 = Legend · ตัวซ้ำ → เศษ · ใช้ตั๋วก่อนเพชร · ดูอัตรา + ประวัติ
- **ไม่มีการซื้อด้วยเงินจริง** — เพชรได้จากด่าน ภารกิจ ความสำเร็จ ล็อกอิน บัตรผ่าน

```

  config.js           ค่าทั่วไป (มูลค่าโดนัท, ตารางเครื่องผลิต, เวอร์ชันเซฟ)
  characters.js       ตัวละคร 37 ตัว (ค่าสถานะ, สกิล, Passive, สายอัปเกรด) + การ์ดซอมบี้ VS
  enemies.js          ศัตรู + บอส (เฟส, สกิล)
  traps.js            กับดัก 15 แบบ
  items.js            สกุลเงิน, วัตถุดิบ, อุปกรณ์, ชุด, บูสเตอร์, สกิลทีม, กาชา, ร้านค้า, โค้ด
  stages.js           แผนที่ + 8 เมือง + ตัวสร้างด่าน (ความยาก) + กิจกรรม/ท้าทาย/CO-OP/Endless/VS
  missions.js         ภารกิจ, ความสำเร็จ, ล็อกอิน, บัตรผ่าน, ข่าว
  story.js            บทสนทนา 8 บท
  assets.js           (สร้างอัตโนมัติ) id ภาพ → ตำแหน่งใน atlas
```
